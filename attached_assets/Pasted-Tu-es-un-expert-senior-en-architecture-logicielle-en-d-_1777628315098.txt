Tu es un expert senior en architecture logicielle, en développement fullstack moderne et en UX/UI design haut de gamme. Ta mission est de concevoir et développer une plateforme de portfolio professionnel en monorepo, hautement performante, sécurisée, évolutive, intelligente et visuellement exceptionnelle.

---

# 🎯 OBJECTIF GLOBAL

Créer une plateforme de portfolio moderne avec deux parties distinctes :

1. **Partie publique (frontend user)**
   Accessible à tous les visiteurs, permettant de découvrir mon profil, mes projets et mon parcours avec une expérience utilisateur immersive et premium.

2. **Partie admin (dashboard privé)**
   Accessible uniquement à moi via une authentification ultra sécurisée, permettant de gérer dynamiquement l’ensemble du contenu du portfolio.

---

# 🧱 STACK TECHNIQUE OBLIGATOIRE

* Frontend : React (Next.js fortement recommandé pour SSR)
* Backend : Node.js + Express
* Base de données : MongoDB
* Stockage médias : Cloudinary
* Authentification : Clerk (remplace Google OAuth)
* Emails : Google Mail API (Nodemailer)
* Messaging : API WhatsApp Business
* IA : Google Gemini API

---

# 🏗️ ARCHITECTURE MONOREPO

Organise le projet avec une structure claire et scalable :

* `/apps/client` → Frontend public
* `/apps/admin` → Dashboard admin
* `/apps/server` → API backend (Express)
* `/packages/ui` → Design system + composants UI réutilisables
* `/packages/utils` → Fonctions utilitaires
* `/packages/types` → Types TypeScript partagés

Utiliser PNPM Workspaces.

# 🎨 UX/UI – DESIGN PREMIUM (STYLE APPLE)

Le design doit être inspiré de l’écosystème Apple :

## 🎯 Principes

* Minimalisme élégant
* Espaces généreux (whitespace)
* Hiérarchie visuelle claire
* Sens du détail extrême

## 🔤 Typographie

* **Ldrish → Titres (headings)**
* **Libre Franklin → Contenu (body text)**

## 🧩 Composants UI

* Cards :

  * ombres très subtiles
  * glassmorphism léger (optionnel)
  * arrondis doux (border-radius élevé)
* Buttons :

  * design clean
  * hover smooth (scale + opacity)
  * transitions naturelles
* Inputs :

  * focus states élégants
  * animations discrètes

## ⚡ Animations

* Framer Motion obligatoire
* Animations :

  * fluides
  * rapides mais naturelles
  * jamais agressives
* Scroll reveal
* Micro-interactions sur hover et click

## 🌗 Expérience

* Dark mode automatique
* Responsive mobile-first
* UX fluide et intuitive
